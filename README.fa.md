### چون «خیلی بازی کردم» برای جدول رتبه‌بندی آمار دقیقی حساب نمی‌شه.

<img src="https://skillicons.dev/icons?i=java,maven,sqlite&theme=dark" />

</div>

---

افزونهٔ آمار پیشرفته و تحلیل زنده که به‌صورت اختصاصی برای سرور **SkyMine** ساخته شده است.

---

## 01 / فناوری‌ها

- Paper 1.21.8
- Java 21
- SQLite
- ذخیره‌سازی غیرهم‌زمان
- HTTP API داخلی مبتنی بر JSON

---

## 02 / آمارهای ثبت‌شده

زمان بازی، ورود و خروج بازیکنان، کیل، مرگ، بلوک‌های شکسته و قرار داده‌شده، استخراج هر نوع بلوک بر اساس جنس، برداشتن و انداختن و ساخت و مصرف آیتم‌ها، مقدار آسیب واردشده و دریافت‌شده و مسافت طی‌شده.

---

## 03 / فرمان‌ها

`/skystats` — نمایش آمار شخصی

`/skystats top <playtime|kills|deaths|blocks>` — نمایش جدول رتبه‌بندی

`/skystats save` — قرار دادن عملیات ذخیره در صف

---

## 04 / API

مستندات API در فایل [docs/api.md](docs/api.md) قرار دارد.

---

## 05 / ساخت

```bash
mvn clean package
```

فایل نهایی افزونه در پوشهٔ `target/` ساخته می‌شود.
